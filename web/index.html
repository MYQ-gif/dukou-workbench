这一步做什么

保留原声、把视频里的中文换成目标语言，并生成对应字幕。卖点讲解、开箱、桌面实拍这类口播素材，一条视频要发多个市场时最省事。

边界（先讲清楚，免得演示翻车）

  • 做：语音识别 → 翻译 → 字幕轨 → 可选 TTS 配音轨
  • 不做：口型同步（lip sync）、原声音色克隆
  • 处理时长：1 分钟视频约 40–90 秒，走异步任务 + 轮询
