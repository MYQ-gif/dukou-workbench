# 三分钟路演脚本（澳门站）

> 目标：三句话讲清"这是给谁的、解决什么、现场看到什么"，剩下时间全部落在屏幕上。

## 0. 开场（20 秒，不切屏）

> "一个人做跨境，最难的不是卖货，是没有团队。
> 拍一张图，美工、翻译、运营、会计这些活全得自己干。
> 渡口把这几件事塞进一个对话里——**拍一张图，剩下的它干**。"

## 1. 现场演示（90 秒，只走一条链路）

顺序固定，别临场换：

1. **发一张实拍图**（提前准备好桌面照，别等上传）
2. 说一句：`做 3 张白底主图，标题写 STAY A WHILE`
3. 等图出来时**不要沉默**，讲这三句：
   - "它在按平台尺寸出：Shopee 是 1242×1660，淘宝是 800×800"
   - "同一个商品，日本站和沙特站的构图不一样——文化适配写进了提示词"
   - "3 张并发，50 秒；一张成本 3 毛"
4. 图出来，点开放大一张（这一下要停 2 秒，让评委看清画质）

## 2. 第二跳（40 秒，展示"不止会出图"）

- 切「记账」：`卖了一单 128.5，运费 30` → 利润立刻出来
- 切「接口」：四行模型状态，点「自检」→ 绿点 → "评委可以自己验，这不是录像"

## 3. 收尾（30 秒，落回人）

> "它不是替代设计师，是让一个人有设计师。
> 现在我们三条链路已经接真模型，一条还在补——这就是 48 小时的边界，我们没装作做完。"

## 备用话术（被问到才说）

| 问题 | 怎么答 |
|---|---|
| 和剪映/Canva 有什么区别 | 它们管单张图；我们管"一个商品在多平台、多语言站得住" |
| 大厂做了怎么办 | 壁垒不在模型，在平台规格库 + 中文图到外文文案的稳定链路，我们拿评测集证明 |
| 视频呢 | Seedance 出 5 秒运镜，已接；不做口型同步，这是明确的边界 |
| 数据哪来的 | 用户自己的商品图，不抓别人数据；账号级隔离 |

## 出场前置检查（5 分钟）

- [ ] `node server.mjs` 起得来，浏览器已开着 `http://localhost:8787`
- [ ] `.env` 里 `AI_MOCK=0`，接口页四行是绿的（视频那行可以黄）
- [ ] 演示商品已存在，图在 `data/uploads/`，别现场等上传
- [ ] 断网预案：`AI_MOCK=1` 切假数据，链路照样能点（提前试一次）
- [ ] 字号调到 125%，投影上后排能看清
