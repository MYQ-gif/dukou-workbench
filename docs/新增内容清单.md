## 二、三个 P0 的样例

### 1）买家问题库（老榆木餐桌 / 家居）

| 层 | 买家会问 | 该由谁回答 |
|---|---|---|
| 场景选型 | 小户型餐厅 1.2m 还是 1.4m？ | 参数页 + 场景图 |
| 成本回报 | 含海运到胡志明市一共多少？ | 报价块 |
| 运营维护 | 实木开裂怎么办？ | FAQ |
| 出品体验 | 桌面是整块还是拼接？ | 参数块 |
| 合规售后 | 有没有熏蒸/原产地证明？ | FAQ + 认证 |

### 2）事实锚点卡

| 原来写的 | 改成 |
|---|---|
| 高品质实木 | 老榆木，含水率 8–10%，桌面厚 4cm |
| 快速发货 | 现货 7 天出库，海运 25 天到胡志明 |
| 售后无忧 | 5 年结构保修，开裂免费换板 |

### 3）六层关键词分层

| 层 | 词例 | 放哪里 |
|---|---|---|
| L1 产品词 | solid wood dining table | 标题前段 |
| L2 场景词 | small apartment dining table | 五点第 1 条 |
| L3 能力词 | handcrafted joinery | 五点第 2–3 条 |
| L4 比较词 | vs MDF veneer | 对比表 |
| L5 行业教育词 | how to care for elm table | 博客/FAQ |
| L6 采购方案词 | bulk order solid wood furniture supplier | 详情首屏 + 独立站落地页 |

## 三、落点

- Asset kind 扩展：`faq` / `param` / `compare` / `anchor` / `keyword_layer` / `visible_score` / `inquiry` / `reply`
- job type：`geo`（问题库+锚点+词表+三件套）、`inquiry`（解析+回信）
- 仓库新增分组「内容资产」（按 kind 侧标）
- 对话入口：说一句「这批买家会问什么」或贴一封询盘即可
