# demo/ —— 「假装生成」的照片池

把你的商品照片丢进这个文件夹（jpg / png / webp 都行，建议 1000px 以上）。

什么时候会用到它：
- 服务以 `AI_MOCK=1` 运行时，出图不会调用任何 API；
- 如果当前商品**有上传过原图**，系统会拿那张原图套版式生成（最接近真实效果）；
- 如果还没有上传图，就从这里按文件名顺序取一张当底图。

想让「出图」看起来更像真的：把同一件商品的多张实拍放进来（正面、侧面、细节），
文件名按顺序排（01-front.jpg、02-side.jpg…），生成时会依次取用。

注意：这个文件夹会进 git（方便队友演示）；不放也行，没有它就用灰底占位图。
